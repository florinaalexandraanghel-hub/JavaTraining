# SAFE DEPOSIT AND WITHDRAW

This project  manages a safe where people can deposit money, both banknotes and coins, and they can withdraw only the same amount that they deposit.
After  every transaction it will be generated a receipt.

### Features

- Read clients, the banknotes and the coins they want to deposit from CSV;
- Safe configuration from CSV;
- Cash deposit;
- Cash withdrawal with Greedy algorithm;
- Generate receipts in text file;
